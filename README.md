# Landing page para un centro clínico veterinario

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una landing page para un centro clínico veterinario. El sitio tiene como propósito presentar la clínica, informar a los visitantes sobre su propuesta de atención y facilitar el contacto con los tutores de mascotas.

## Objetivos

- Dar a conocer el centro clínico veterinario en línea.
- Presentar de forma clara la información y los servicios de la clínica.
- Facilitar la navegación y el acceso a los medios de contacto.
- Ofrecer una experiencia visual ordenada y adaptable a distintos dispositivos.

## Trabajo realizado

Se desarrolló una página de presentación enfocada en las necesidades de una clínica veterinaria. Se organizó el contenido para que los visitantes puedan conocer el centro, revisar la información disponible y encontrar cómo comunicarse con él.


## Tecnologías utilizadas

    - ASTRO
    - React
    - Tailwind
    - Shadcn
    - TypeScript
